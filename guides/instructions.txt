How to use basic Pharo functionalities
    To exit Pharo
        In Pharo itself
        Click/Pharo/Quit
            A question will appear
            Click/Save/
    To start Pharo again
        In Pharo Launcher
        Select/Pharo 14.0 - 64bit (development version, latest)/
            The row will be highlighted blue
        Click/Launch button/
    To open image folder
        In Pharo Launcher
        Right click/Pharo 14.0 - 64bit (development version, latest)/
        In context menu
        Click/Show in folder/
            Windows 11 Window Explorer will open
                Will show contents C:\Users\<your_user>\Documents\Pharo\images\<image_name>
                Example: C:\Users\morgan\Documents\Pharo\images\Pharo 14.0 - 64bit (development version, latest)

In Pharo itself
    To open System Browser
        Click/Browse/System Browser/
    To open Playground
        Click/Browse/Playground/
    Create a package
        In System Browser
        Right click/Area in top left panel/
            A context menu will appear
        In context menu
        Click/New package/
            A window will appear
        Name the package
            MyCounter
        Click/Ok/
            MyPackage will be automatically selected
    Create a class
        Right click/Area in 2nd top panel from the left/
            The pannel near the middle with a Filter... at its bottom
            A context menu will appear
        In context menu
        Click/New class/
            A window will appear
        In the Information Required window, type
            Object << #MyCounter
                layout: FixedLayout;
                traits: {};
                slots: {#value};
                sharedVariables: {};
                sharedPools: {};
                tag: '' ;
                package: 'MyCounter'
        Click/Ok/
            MyCounter class will appear in the class panel
            MyCounter is automatically selected
    Create method
        Click/Inst. side radio button/
        Click/+ Inst. side method tab/
        Replace text, with 
            value: anObject

                value := anObject
        In text editor
            Right click/Empty spaces/
            In context menu
                Click/Accept/

How to Setup the Visual Studio solution
    In Windows search, type
        CMake (cmake-gui)
        Select/Cmake (cmake-gui)/
    In CMake (cmake-gui)
        Click/Browse Source.../
            Select folder
            C:\occt_projects\project_opencascade_demo   
        Click/Browse Build.../
            Select folder
            C:\occt_projects\project_opencascade_demo\build_vc145
        Click/Configure/
            Proceed with default options
            An error message will appear
        Click/OCCT_SOURCE_DIR/
            Fill
            C:\occt_projects\project_opencascade_demo\occt\OCCT-8_0_0_rc4
        Click/Configure/
            An error message will appear
            On Error window
                Click/OK/
        Click/3RDPARTY_DIR/
            Fill 
            C:\occt_projects\project_opencascade_demo\occt\3rdparty
        Click/BUILD_USE_PCH/
            Tick checkbox
        Click/INSTALL_DIR/
            Fill
            C:\occt_projects\project_opencascade_demo\occt_install_vc145
        Click/INSTALL_FREETYPE/
            Tick checkbox
        Click/INSTALL_TCL/
            Tick checkbox
        Click/INSTALL_TK/
            Tick checkbox
        Click/USE_RAPIDJSON/
            Tick checkbox
        Click/Configure/
            Wait approximately 20s
            Ignore Warnings
        Click/Generate/
            Wait approximately 10s
            No errors appear
            Solution file created at
                C:\occt_projects\project_opencascade_demo\build_vc145
        Click/Open Project/
            Visual Studio 2026 will open

                Wait apprximately 4 minutes

            Click/Reload all/
        In output
            2 succeeded
            0 failed
            0 up-to-date
            0 skipped
        Installed files at
             C:\occt_projects\project_opencascade_demo\occt_install_vc145    
   
In Windows 11 File Explorer
    Go to C:\occt_projects\project_opencascade_demo\install_vc145\win64\vc14\bind
    Double click/DRAWEXE.exe/

In DRAWEXE
    Type/pload ALL/
        wait until 1 is printed
    Type/box a 10 10 10/
    Type/vinit display/
        A 3D View window will appear
    Type/vdisplay a/
        A box will appear in 3D View
    
In 3D View 
    Hold left click black space/Drag to rotate object/
    Hold middle mouse button/Drag to pan camera/
    Scroll mouse wheel/Zoom in and out camera/
    Ctrl + S/enable shaded display/
    Press f key/zoom to shape/
