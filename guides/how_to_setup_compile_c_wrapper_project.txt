How to setup & compile C wrapper dll

Complete OpenCASCADE setup first
    Follow
        how_to_setup_build_occt.txt
    Until OpenCASCADE is installed at
        C:\dev\opencascade\occt_install\v8_0_0_rc5
    OpenCASCADEConfig.cmake should exist at
        C:\dev\opencascade\occt_install\v8_0_0_rc5\cmake\OpenCASCADEConfig.cmake

In Windows 11 File Explorer
    Create folder
        C:\dev\opencascade
    Create folder
        C:\dev\opencascade\tmp
    Extract project_my_c_wrapper.zip contents to
        C:\dev\opencascade\project_my_c_wrapper
    The wrapper project root should contain
        C:\dev\opencascade\project_my_c_wrapper\CMakeLists.txt
        C:\dev\opencascade\project_my_c_wrapper\src\my_c_wrapper.cpp
        C:\dev\opencascade\project_my_c_wrapper\src\my_c_wrapper.h

Setup the Visual Studio solution
    In Windows search, type
        CMake (cmake-gui)
        Select/Cmake (cmake-gui)/
    In CMake (cmake-gui)
        Click/Browse Source.../
            Select folder
            C:\dev\opencascade\project_my_c_wrapper
        Click/Browse Build.../
            Select folder
            C:\dev\opencascade\tmp\project_my_c_wrapper_build_vc143_x64
        Click/Configure/
            Select generator
                Visual Studio 18 2026
            Select platform
                x64
            Click/Finish/
        Click/OpenCASCADE_DIR/
            Fill
            C:\dev\opencascade\occt_install\v8_0_0_rc5\cmake
        Click/OCCT_SOURCE_DIR/
            Fill
            C:\dev\opencascade\OCCT
        Click/Configure/
            Wait until output shows
                Configuring done
        Click/Generate/
            Wait until output shows
                Generating done
            Solution file created at
                C:\dev\opencascade\tmp\project_my_c_wrapper_build_vc143_x64\my_occt_c_wrapper.slnx
        Click/Open Project/
            Visual Studio 2026 will open

Build Project
    In Visual Studio 2026
        In toolbar
            Select/Debug/
            Select/x64/
        Click/Build/Build Solution/
            In output
                2 succeeded
                0 failed
            dll file created
                C:\dev\opencascade\tmp\project_my_c_wrapper_build_vc143_x64\Debug\my_occt_c_wrapper.dll

Copy DLLs to Pharo image folder
    Copy wrapper DLL from
        C:\dev\opencascade\tmp\project_my_c_wrapper_build_vc143_x64\Debug\my_occt_c_wrapper.dll
    Copy all .dll and .pdb files from
        C:\dev\opencascade\occt_install\v8_0_0_rc5\win64\vc14\bind
    To
        C:\Users\<your_user>\Documents\Pharo\images\<image_name>
        Example: C:\Users\morgan\Documents\Pharo\images\pharo_opencascade_integration
