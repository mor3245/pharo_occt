How to setup Pharo Project

In Windows 11
    In search, type
        Pharo Launcher
        Select/Pharo Launcher/
        
In Pharo Launcher
    Click/New button/
    Select/Pharo 14.0 - 64bit (development version, latest)/
    Click/Image name:/, type
        pharo_opencascade_integration
    Click/Create image/
        New image created at
        C:\Users\<your_user>\Documents\Pharo\images\pharo_opencascade_integration
        Example: C:\Users\morgan\Documents\Pharo\images\pharo_opencascade_integration
        Pharo automatically starts
    Right click/pharo_opencascade_integration
    In context menu
    Click/Show in folder/
    Windows 11 Window Explorer will open
        Will show contents C:\Users\<your_user>\Documents\Pharo\images\pharo_opencascade_integration
        Example: C:\Users\morgan\Documents\Pharo\images\pharo_opencascade_integration
    In Pharo itself
        Click/Pharo/Quit/
            A question will appear
            Click/Save/

In Windows 11 File Explorer
    Go to
    C:\dev\opencascade\occt_install\v8_0_0_rc5\win64\vc14\bind
    Click/Sort/
    In drop down menu
        Click/Type/
    Click/Sort/
    In drop down menu
        Click/Ascending/
    Click/View/
    In drop down menu
        Click/Details/
    In Content Panel
        Left click/freetype.dll/
        Scroll down to/TKXSDRAWVRML.dll/
        Holding Shift/Left click/TKXSDRAWVRML.dll/
        Release Shift/
        Right click/Highlighted rows/
        In context menu
            Click/Copy/

In Windows 11 File Explorer
    Go to
    C:\Users\morgan\Documents\Pharo\images\pharo_opencascade_integration
    Right click/An empty space of Content Panel/
    In context menu
        Click/Paste/
        
In Windows 11 File Explorer
    Go to
    C:\dev\opencascade\tmp\project_my_c_wrapper_build_vc143_x64\Debug
    Right click/my_occt_c_wrapper.dll/
    In context menu
        Click/Copy/
    
In Windows 11 File Explorer
    Go to
    C:\Users\morgan\Documents\Pharo\images\pharo_opencascade_integration
    Right click/An empty space of Content Panel/
    In context menu
        Click/Paste/

In Pharo Launcher
    Click/pharo_opencascade_integration/
    Click/Launch/
    Pharo will open
    
In Pharo
    Click/Browse/Playground/
    In Playground
        Type
            Metacello new
              baseline: 'PharoOCCT';
              repository: 'github://mor3245/pharo_occt:master/src';
              onConflictUseIncoming;
              load.
        Right click/Playground text/
        In context menu
            Click/Do it/
        The BaselineOfPharoOCCT package will load
        The LibImports-UFFI-CWrap package will load
        The MyOpenCascade packages will load
