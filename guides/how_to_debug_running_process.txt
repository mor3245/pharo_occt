In Pharo Launcher
    Right click/<your_image_name>/
        Example: Right click/Pharo 14.0 - 64bit (development version, latest)/
    In context menu
    Click/Show in folder/
        Windows 11 Window Explorer will open
            Will show contents C:\Users\<your_user>\Documents\Pharo\images\<image_name>
            Example: C:\Users\morgan\Documents\Pharo\images\Pharo 14.0 - 64bit (development version, latest)
    
In Windows 11 File Explorer
    Go to C:\dev\opencascade\occt_install\v8_0_0_rc5\win64\vc14\bind
    Copy all .dll and .pdb files
    To
    C:\Users\<your_user>\Documents\Pharo\images\<image_name>
            Example: C:\Users\morgan\Documents\Pharo\images\Pharo 14.0 - 64bit (development version, latest)

In Windows 11 File Explorer
    Go to C:\dev\opencascade\tmp\project_my_c_wrapper_build_vc143_x64\Debug
    Copy
        my_occt_c_wrapper.dll
    To
    C:\Users\<your_user>\Documents\Pharo\images\<image_name>
            Example: C:\Users\morgan\Documents\Pharo\images\Pharo 14.0 - 64bit (development version, latest)
            
In Pharo Launcher
    Click/<your_image_name>/
        Example: Click/Pharo 14.0 - 64bit (development version, latest)/
            The row will be highlighted blue
    Click/Launch button/

In Windows 11 File Explorer
    Go to C:\dev\opencascade\tmp\project_my_c_wrapper_build_vc143_x64
    Double click/my_occt_c_wrapper.slnx/
    Visual Studio 2026 will open

In Visual Studio 2026
    In Solution Explorer
        Click/my_occt_c_wrapper/Source Files/my_c_wrapper.cpp
    In my_c_wrapper.cpp
    Put a breakpoint inside function
        cxxCreateBox
    Click/Debug/Attach to Process.../
    In Attach to Process
        Click/Tree/
        In Filter processes (Ctrl + E), type
            Pharo
        Select/Pharo.exe/
            With Pharo image file path as title
            Example:        C:\Users\morgan\Documents\Pharo\images\pharo_opencascade_integrationX\pharo_opencascade_integrationX.image
        Click/Attach/

In Pharo
    Open System Browser
    Go to package
        MyOpenCascade-API-Test
    Go to class
        MyShapeFactoryTest
    Go to method
        testDefaultBoxFactoryCreatesNamedNativeShape
    Run test
        Pharo UFFI loads DLLs lazily; the DLL is only loaded into the process the first moment a function inside is actually called.
        Visual Studio will stop at cxxCreateBox in my_c_wrapper.cpp.
        Pharo window will be uninteractable.

In Visual Studio 2026
    These buttons are on the right side of the red square pause button.
        Step into is a blue arrow pointing down to the blue dot.
        Step over is a blue arrow pointing over and to the right of the blue dot.
        Step out is a blue arrow pointing up from the blue dot.
    Click/Step into/
        Debugger will step into
            cxxBoxNew
    Click/Step into/
        Debugger may step into OpenCASCADE source from inside cxxBoxNew if OCCT_SOURCE_DIR was configured when generating the wrapper solution.
    Click/Step out/
        Debugger will return to my_c_wrapper.cpp
    Click/Step over/
        Debugger will continue through
            cxxToShape
            cxxMakeBoxDelete
    Click/Continue/
    The previously open Pharo window will reappear.

In Pharo
    The test runner will continue.
    Green test result will appear.
    The test has passed.
